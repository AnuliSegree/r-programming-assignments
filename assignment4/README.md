# Assignment 4 – Hospital Data Analysis

This assignment analyzes a hospital dataset of 10 patients using R.

## Files included
- hospital_assignment.R → R script used to create plots
- example_boxplot.png → example boxplot from vector A
- example_histogram.png → example histogram from vector B
- bp_boxplot_hist.png → blood pressure analysis plots

## Description
Boxplots and histograms were used to visualize blood pressure values and understand their relationship with doctor assessments and final emergency decisions.
